# 镜序 MVP

面向高频连载漫剧创作者的单集分镜粗剪工作台。

## 核心链路

1. 输入定稿脚本与角色参考图。
2. 本地拆解为 8–12 个可编辑镜头。
3. 逐镜保留、修改或重做。
4. 预览粗剪并导出项目 JSON 与 SRT 字幕。

当前版本使用本地启发式拆镜和视觉占位引擎，便于在没有模型密钥的情况下验证工作流、镜头接受率、重做次数和完成时间。后续可在保持交互不变的前提下接入图像与视频模型。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可。

## 验证重点

- 从脚本到可编辑粗剪的总时间
- 首次生成镜头接受率
- 单镜平均重做次数
- 导出后进入真实制作流程的比例
